# BoL 品牌定位与 VI 手册

> 版本：v0.1（基于仓库现有资料整理）  
> 更新时间：2026-11-07  
> 适用范围：BoL 俱乐部、`BoL Club` 门户网站、微信小程序「BoL万象博联」、活动海报与社群传播物料

## 0. 使用说明

这是一份“现状盘点 + 可执行建议”的工作版品牌手册。

- **现状事实**：来自仓库中的 README、公开页面盘点、截图测量、已有代码和素材记录。
- **建议规范**：为门户和后续传播建立统一标准，便于设计、开发和活动运营执行。
- **待确认事项**：当前资料无法证明为正式决策的内容，必须由品牌负责人确认后才可作为最终规范。

当前没有发现一份由品牌负责人签发的正式 VI 手册。因此，本文件不把推断出的英文释义、色值或 Logo 结构描述成已批准的品牌资产。

资料基线为本地提交 `3efe155d`，原版截图主要采集于 2026 年 10 月。门户首版文案明确是占位内容，不能单独证明会员构成、覆盖城市或活动筛选机制；本文未进行外部竞品调研或用户访谈。

## 1. 品牌概况

### 1.1 品牌名称

| 使用场景 | 当前名称 | 使用建议 |
| --- | --- | --- |
| 对外英文品牌 | **BoL Club** | 门户导航、活动英文标题、Logo 锁定时使用 |
| 中文品牌 | **BoL 俱乐部** | 正式中文介绍、页脚、媒体资料使用 |
| 微信小程序 | **BoL万象博联** | 微信搜索、报名引导、会员服务入口使用 |
| 域名 | **bo-link.com** | 门户网站与品牌数字资产 |

首页品牌介绍长图写有 `BoL（BoLink）Club`：“Bo（博）”寓意“多元、丰富、广阔”，“L（Link）”代表“链接与联系”。其中的使命表述是让更多人彼此遇见、深度链接、共同成长。另一份活动详情长图记录还出现 “Business Opinion Leader” 与 “Bridge of Links”。这些写法的层级尚未统一，建议负责人确认最终标准。

### 1.2 一句话定位

**建议整合表述：BoL 是面向各行业海归与菁英的商业与生活平台，以线下活动为入口，让更多人彼此遇见、深度连接、共同成长。**

### 1.3 品牌角色

BoL 的角色不是泛泛的活动售票平台，也不是只围绕单一行业的职业协会。它更接近一个由活动、会员权益和长期社群关系组成的线下连接平台：

1. 用活动制造自然认识彼此的场景。
2. 用主题、场地和人数控制保证交流质量。
3. 用会员、权益卡和后续服务延长一次活动后的关系。
4. 逐步沉淀跨城市、跨行业、跨兴趣的可信连接网络。

## 2. 品牌定位分析

### 2.1 目标人群

#### 核心人群

- 各行业海归、留学经历人群与具有国际化生活/工作背景的人群。
- 深圳、广州及大湾区的职场菁英、创业者、专业人士和高质量生活方式参与者。
- 希望扩大真实人脉、寻找合作机会、参与主题活动或进入更高质量社交场景的人。

#### 次级人群

- 对 AI、商业出海、跨境、创意、运动、宠物、非遗和生活方式主题感兴趣的人。
- 有组织活动能力、社群资源或专业内容，希望成为活动主理人、领队、导师、顾问或合作伙伴的人。

#### 不应作为品牌默认标签的人群描述

“海归”是现有活动定位和社群语境，不应被视觉化为固定脸型、服装、肤色或阶层符号。传播中要表达真实的经历、兴趣与交流状态，不要用刻板的“精英脸”代替真实人物。

首页长图列举海归、985/211/MBA 校友、创业者、接班二代、投资人、企业中高管和知名博主等，称主要活跃在粤港澳大湾区和上海。这是历史宣传自述，并非已核实的入会条件。长图中“超过 25,000 名会员”“90% 以上具有海外背景”缺少统计截止日期和口径，不能直接作为当前官网数据背书。

### 2.2 用户需求

以下为依据业务形态提出的假设，尚待用户访谈、活动反馈与复购数据验证。

| 用户需求 | BoL 的回应 |
| --- | --- |
| 想认识有共同话题的人 | 通过 Networking、主题沙龙、AI 酒会等活动降低第一次认识的压力 |
| 想找到高质量合作或资源 | 通过行业、主题、场地与活动组织方式提高交流密度 |
| 想拥有持续的活动与会员权益 | 通过免费会员、付费会籍、权益卡与会员价活动形成长期关系 |
| 想在正式与轻松之间找到平衡 | 以酒会、私宴、运动、游艇、宠物和节日活动覆盖不同社交状态 |
| 想被尊重并保护隐私 | 传播素材应保护嘉宾身份，活动宣传避免把虚构人物写成真实到场嘉宾 |

### 2.3 核心价值主张

**把“认识人”变成值得赴约的体验，把一次见面变成可以持续的连接。**

首页现有品牌自述使用“破圈共融，互相成长”。上面的价值主张是本手册的整合建议，尚未成为正式批准口号。

这里的“质量”具体体现在：

- 有明确主题，而不是没有内容的泛社交。
- 有合适场地、人数和节奏，而不是无边界的人群堆积。
- 有真实的互动和可记忆的现场，而不是只在手机上浏览。
- 有活动后的会员服务和关系延续，而不是买票即结束。

### 2.4 品牌差异化方向

以下是策略对照，不是对具体竞品的调查结论。

| 普通活动平台 | BoL 应建立的差异 |
| --- | --- |
| 只展示时间、地点、价格 | 同时展示活动语境、人与现场氛围 |
| 活动之间彼此孤立 | 通过会员、权益和系列活动形成长期关系 |
| 以流量和低价为中心 | 以匹配质量、体验质量和信任感为中心 |
| 过度商业促销 | 商业交流与生活方式并置，保持克制而有吸引力 |

### 2.5 品牌架构建议

```text
BoL
├── BoL Club / BoL 俱乐部       品牌母体与对外门户
├── BoL万象博联                 微信小程序与会员服务入口
├── 活动系列                    Networking、AI、沙龙、运动、私宴等
└── 会员与权益                  星光、星辰、酒会优享卡等具体产品
```

活动名称可以有个性，但要始终挂在 BoL 母品牌下。建议统一写法为“BoL + 活动主题”，避免每个活动被包装成互不相关的独立品牌。

## 3. 现有品牌调性

### 3.1 从现有资料可以确认的调性

小程序首页、会员介绍页、活动详情和活动海报反复出现以下视觉和内容特征：

1. **暗色、高级、沉浸**：黑色导航和大面积黑底，搭配暗酒红、金色或暖米色。
2. **现场感**：首屏视频、活动照片、酒杯、餐桌、灯光和人物互动是主要内容。
3. **克制的奢华**：金色用于 Logo、价格、边框和重点信息，避免大面积亮金造成俗艳。
4. **跨行业与多兴趣**：Networking、AI、商业、运动、游艇、宠物、节日等内容共存。
5. **正式与松弛并置**：私宴、酒会和商业交流提供正式感；微醺夜话、乱讲 PPT、宠物主题提供亲近感。
6. **会员感**：会员卡、权益、价格和专属活动使用深色卡片、金色细节和仪式感排版。

### 3.2 当前调性的关键词

**高级｜真实｜克制｜开放｜有趣｜有连接感｜城市生活方式｜可参与**

其中“高级”应理解为选择和体验的质量，而不是炫耀性消费；“菁英”应理解为人的经历、能力和好奇心，而不是财富或外表。

### 3.3 调性张力

BoL 的识别度来自几组需要同时成立的张力：

| 一端 | 另一端 | 执行原则 |
| --- | --- | --- |
| 高级 | 亲近 | 材质和排版精致，文案说人话 |
| 商业 | 生活 | 有专业主题，也有酒会、运动与兴趣活动 |
| 私密 | 开放 | 审核和服务保持边界，活动主题保持友好 |
| 克制 | 热闹 | 视觉克制，照片保留现场能量 |
| 国际化 | 本地化 | 中英适度混用，内容落在真实城市和具体场景 |

### 3.4 当前需要修正的风险

- 现有不同页面的白色、黑色、金色和红色使用较为分散，门户需要建立统一色彩层级。
- “高端”“顶尖”“菁英”等词如果单独使用，容易变成空泛的身份营销；应尽量用活动事实和体验细节证明质量。
- Logo 在资料中存在“8o/BoL”视觉辨识风险，门户需要使用单一、可读、可缩放的正式版本。
- 小程序历史页面有“发现”实际指向购物车等遗留配置，门户导航不应复制这种信息架构问题。
- 活动图片中涉及真实嘉宾隐私，发布前必须确认授权、打码或使用经过人物重构的素材。

## 4. VI 核心规范（工作版）

### 4.1 Logo 与标志系统

#### 现有资产

仓库中有一个 `miniprogram/client/miniprogram/assets/logo-bol.svg`，图形由三个相连的圆形构成；“多人、连接和网络”是可供讨论的设计解读，并非已证实的官方寓意。小程序截图中可见黑底金色/米色的组合。门户与小程序的现有 SVG 几何细节不同，且门户首版是占位稿：两者均须与正式源文件核对，不能直接视作印刷母版。

#### 建议主标志

- 图形标志：三个相连的圆形结构。
- 英文标准字：`BoL Club`。
- 中文辅助字：`BoL 俱乐部`。
- 默认锁定：图形 + `BoL Club` 横向组合。
- 活动物料可使用图形单独作为角标，但首次出现应同时出现完整标准字。

#### Logo 使用规则

- 深色底使用米白或金色版本；浅色底使用黑色版本。
- 建议以图形总高 H 为基准，四周保留至少 0.25H 安全空间；待正式母版确认后验证。
- 不拉伸、不压扁、不旋转、不加阴影、不添加渐变描边。
- 不把图形与活动名称随意拼成新的 Logo。
- 不在照片高亮、人物脸部或复杂纹理上直接放置低对比 Logo。

#### 待确认

正式 Logo 源文件、标准字字体、最小使用尺寸、黑金版本是否为正式批准资产，需由品牌负责人确认。

制作起点可暂按图形不少于 24px／8mm、完整横向组合不少于 120px／30mm，分别在屏幕和印刷打样检查可读性；这些只是待验证的建议值。

### 4.2 色彩系统

下表为未获批准的工作色板：墨黑、深炭、暖白、灰米、香槟金与分隔线取自门户占位 CSS；会员金取自小程序代码；暗酒红来自历史截图估计。屏幕使用 sRGB/HEX，印刷的 CMYK 或专色须根据纸张、油墨和工艺单独打样确定。

#### 门户建议色板

| 角色 | Token | HEX | 用途 |
| --- | --- | --- | --- |
| 墨黑 | `--bol-ink` | `#0B0B0C` | 页面底色、深色导航 |
| 深炭 | `--bol-charcoal` | `#151517` | 卡片、浮层、内容分区 |
| 暖白 | `--bol-ivory` | `#F2EFE9` | 主标题、主要正文 |
| 灰米 | `--bol-muted` | `#A3A09A` | 辅助说明、日期、次要信息 |
| 香槟金 | `--bol-champagne` | `#D8B98A` | Logo、按钮边框、重点数字 |
| 会员金 | `--bol-member-gold` | `#BF8943` | 会员价格、权益重点、深色金色卡片 |
| 暗酒红 | `--bol-wine` | `#5A1A1E` | 酒会、私宴、活动海报的情绪色 |
| 分隔线 | `--bol-line` | `#2A2A2E` | 边框、分隔线、卡片描边 |

使用比例建议：墨黑/深炭约 65%，暖白/灰米约 25%，金色约 8%，酒红及其他活动色约 2%。金色是识别点，不是大面积背景。

#### 色彩禁用

- 不使用高饱和正红作为默认品牌主色。
- 不同时使用多种金色渐变制造廉价金属效果。
- 不把金色文字放在亮白或复杂照片上而不加对比处理。
- 活动可以有主题色，但必须保留 BoL 黑色、Logo 或版式中的至少一个品牌锚点。

正文与背景对比度以 WCAG AA 4.5:1 为验收标准，大字至少 3:1；金色和灰色文字须实测。状态不能只靠颜色传达，键盘焦点需清晰可见，视频提供静音控制并尊重减少动态设置。

### 4.3 字体与文字层级

#### 数字与中文

- 中文优先：`PingFang SC`、`HarmonyOS Sans SC`、`Microsoft YaHei`。
- 英文和数字优先使用系统无衬线；价格可使用更有秩序感的数字字体，但要保证可读性。
- 不在同一张海报中混用超过两种字体家族。

#### 门户网页层级建议

| 层级 | 建议字号 | 字重 | 用途 |
| --- | ---: | ---: | --- |
| Display | 48–72px | 500–600 | 首页主标题 |
| H1 | 32–48px | 500–600 | 页面主标题 |
| H2 | 24–32px | 500–600 | 模块标题 |
| H3 | 18–22px | 600 | 卡片标题 |
| Body | 16–18px | 400 | 介绍正文 |
| Caption | 12–14px | 400–500 | 日期、辅助信息 |

标题要短，正文要具体。英文活动名可保留原有大小写（如 `Networking`、`AI`、`PPT`），中文正文避免过度夹杂英文。

移动端正文建议 16px 起、行高 1.6–1.8；英文标签不承担唯一的必要信息。系统字体栈不意味着允许提取或分发字体文件，新增字体前需确认网页嵌入和商业印刷授权。

### 4.4 版式与形状

- 以大留白、强对齐、少装饰建立高级感。
- 门户采用 8px 间距基数；卡片圆角建议不超过 8px，按钮胶囊可用于行动按钮和标签。
- 重要内容优先使用全宽照片或视频，避免把大量文字压在首屏。
- 金色细线、短横线和小型编号可作为节奏标记，避免满屏边框。
- 移动端先设计：正文宽度控制在舒适阅读范围，桌面端再扩展到大图和多列布局。

### 4.5 摄影与视频

#### 应该拍什么

- 人与人正在交流的瞬间：举杯、倾听、交换名片、共同观看、运动互动。
- 场地材质和光线：酒杯、餐桌、布料、金属、木材、城市夜景。
- 真实的群体关系：小组对话、不同年龄与行业的人自然共处。
- 活动结束后仍然有余韵的细节：桌面、手部、灯光、空场和局部物件。

#### 不应该拍什么

- 统一摆拍、所有人看镜头的“合照墙”作为唯一素材。
- 夸张奢侈品、豪车和无上下文的财富符号。
- 过度磨皮、塑料皮肤、重复脸、明显 AI 生成痕迹。
- 未获得授权的可识别嘉宾、手机屏幕、名牌和私人信息。

#### 画面处理

- 基础色调：低饱和、深背景、暖高光、保留真实肤色。
- 黑色区域要保留层次，不能压成一整块死黑。
- 金色和酒红可以作为环境光或重点物件出现，避免整张图套统一滤镜。
- 活动宣传若使用人物重构图，不写成真实到场记录；可采用素材文档提出的“活动氛围示意”标注，具体文字与渠道由负责人确认。

### 4.6 图形、图标与动效

- 图标使用线性、圆角、轻量笔画，与 Logo 的圆形结构呼应。
- 不使用复杂的 3D 金属图标、厚重拟物或高饱和渐变图标。
- 动效以淡入、轻微位移、图片裁切和滚动视差为主，时长 180–500ms。
- 首屏视频默认静音，提供明显的声音控制；尊重移动端流量和可访问性。
- 动效不能阻塞信息阅读、报名按钮或页面加载。

## 5. 文案与语言风格

### 5.1 文案人格

BoL 说话像一位有品位、懂活动、愿意介绍朋友认识的主理人：清楚、克制、具体、友好，有判断但不摆架子。

### 5.2 推荐用词

**真实连接、值得赴约、主题清晰、现场交流、跨行业、会员权益、精选场地、共同兴趣、城市生活、长期关系。**

### 5.3 谨慎使用

“顶尖、最高端、唯一、顶级资源、稳赚、保证认识大佬”等绝对化或承诺性词语。除非有可核验依据，不使用“25,000+”等规模数字作为长期固定口号。

### 5.4 文案示例

#### 品牌介绍

> BoL 以高质量线下活动为入口，连接各行业海归与职场菁英。我们在酒会、沙龙、运动和私宴中，创造更自然、更有内容的认识方式。

#### 活动 CTA

- 查看近期活动
- 认识同频的人
- 了解会员权益
- 申请加入 BoL
- 先看看下一场活动

#### 活动描述公式

```text
主题是什么 + 适合谁来 + 现场会发生什么 + 为什么值得赴约
```

示例：

> 一场围绕 AI 与品牌出海的晚间交流。适合正在做产品、增长或跨境业务的人，在轻松的酒会氛围里交换经验，也认识正在解决相似问题的人。

## 6. 门户网站落地建议

门户 `portal/web` 当前是 React + Vite + TypeScript 的静态单页，建议沿用现有技术栈，先把品牌主叙事做清楚，再决定是否迁移多页面框架。

### 6.1 首页信息架构

1. **Hero**：一句定位 + 活动现场视频/主图 + “查看近期活动”。
2. **品牌介绍**：BoL 解决什么问题、如何创造连接。
3. **活动矩阵**：Networking、AI、沙龙、运动、私宴、生活方式等系列。
4. **现场证据**：真实摄影、短视频和活动回顾。
5. **会员关系**：免费会员、付费会籍、权益卡的关系说明，避免只展示价格。
6. **加入方式**：引导至微信小程序「BoL万象博联」。
7. **页脚**：品牌名称、联系方式/社媒入口、备案号（备案通过后填入）。

### 6.2 设计优先级

- 先建立首屏品牌记忆和活动氛围，再增加功能模块。
- 活动照片和视频优先于大段抽象宣言。
- 每个页面只保留一个主要行动按钮。
- 所有文案集中在 `portal/web/src/content.ts`，方便校对和后续内容运营。

### 6.3 物料应用规范（建议）

| 物料 | 制作起点 | 验收重点 |
| --- | --- | --- |
| 活动海报 | 竖版 3:4 或 4:5；品牌、主题、日期/城市、内容、报名入口依次呈现 | 缩略图可识别主题，时间地点清楚，二维码实机可扫 |
| 社群分享卡 | 横版 16:9；一句主题配现场图及 BoL 署名 | 检查平台裁切，不把长海报整体缩小 |
| 会员卡 | 横卡约 1.6:1；统一标志、等级名和权益入口 | 区分免费等级、付费会籍与次卡，不公开真实会员号 |
| 现场导视 | 大字号短标题、Logo 和路线信息分层 | 按实际观看距离和场地尺寸核验 |
| 印刷邀请函 | 黑色或暖白基底，金色小面积点缀 | 出血以印厂要求为准，烫金独立图层并打样 |
| 头像/favicon | 使用确认后的小尺寸图形版，四周留白 | 圆形裁切及 16、32、48px 逐档检查 |

以上为制作建议，须以正式资产及实际渠道要求验证。

### 6.4 当前上线边界

域名 `bo-link.com` 正在 ICP 备案期间，备案通过前只允许本地预览或部署到其他已备案预览域名。不得执行 `portal/deploy/deploy.py` 的生产发布，也不得执行 `ops/server/apply_nginx.py --go-live`。

## 7. 品牌治理与资产管理

### 7.1 文件建议

```text
portal/docs/
├── BoL品牌定位与VI手册.md     本文件
├── 设计/                       正式设计稿、色板、Logo 规范
├── 素材/                       经过授权的门户图片与视频清单
├── 内容/                       页面文案、活动文案、SEO 文案
└── 记录/                       评审意见、版本变更、上线记录
```

### 7.2 发布前检查

- Logo 是否使用正式版本，是否清晰可读。
- 黑色背景是否有层次，文字对比度是否足够。
- 所有活动图片是否确认肖像和隐私处理。
- 活动日期、价格、会员权益和城市是否与实际信息一致。
- “海归”“菁英”“高端”等定位表述是否有具体活动内容支撑。
- 备案号是否仅在备案通过后填写和发布。
- 是否误把氛围示意图写成真实活动记录。

### 7.3 变更规则

1. 色板、Logo、品牌名称和核心定位属于品牌级变更，需要负责人确认。
2. 单场活动海报可以拥有自己的主题色，但不得改变母品牌 Logo 和基本识别结构。
3. 运营文案和页面模块可以快速迭代，但涉及会员承诺、价格、权益和法律信息时必须以后台或正式决策为准。

## 8. 经营验证与推进顺序

| 维度 | 当前判断 | 建议验证 |
| --- | --- | --- |
| 优势 | 活动品类多样，黑金视觉具有连续性，已有活动回顾和会籍产品 | 核查各系列举办频率、满意度与复购 |
| 弱项 | 名称和释义存在不同版本，会员等级、付费会籍与次卡容易混淆 | 访谈首次用户能否说清 BoL 和会员价值 |
| 机会 | 用跨行业主题与城市系列沉淀长期关系，门户承载品牌信任 | 跟踪门户到小程序的路径与活动复访 |
| 风险 | 可能被误解为泛售票或单一类型社交；过期数据和权益影响信任 | 测试不同叙事并定期复核公开承诺 |

审核制单身私宴是已有活动类型之一，不等于全部活动或品牌唯一定位。建议先统一名称、释义、数据与权益，再确认 Logo 和色彩母版，制作门户、海报和会员介绍模板，最后通过小范围用户访谈验证。指标可从品牌理解、报名来源、到场率、满意度和复购入手，先定义口径，再设目标。
